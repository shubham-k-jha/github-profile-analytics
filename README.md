## ✨ What Is This?

**GitHub Profile Analytics** is a self-hosted analytics and visitor-tracking system built around the GitHub API, Vercel serverless functions, and Redis.

The project was created to turn a GitHub profile into a small **data analytics dashboard**, combining:

- 👀 Profile view tracking
- 📊 GitHub profile statistics
- ⭐ Repository star information
- 🍴 Repository fork information
- 👥 Follower statistics
- 💻 Programming-language analysis
- 🏆 Top repository information
- ⚡ Recent public GitHub activity
- 📅 Monthly visitor statistics
- 📈 Historical profile-view trends

The application is deployed on **Vercel** and uses **Redis** for persistent visitor-count storage.

### 📊 Analytics Dashboard

👉 **[Open the Live Dashboard](https://github-profile-analytics-rho.vercel.app/dashboard.html)**

The dashboard provides an overview of:

| Metric | Description |
|---|---|
| 👀 Profile Views | Recorded visits through the analytics endpoint |
| 📦 Repositories | Public GitHub repositories |
| ⭐ Stars | Repository star count |
| 🍴 Forks | Repository fork count |
| 👥 Followers | GitHub followers |
| 📅 Monthly Views | Current-month profile views |
| 💻 Languages | Programming languages used |
| 🏆 Top Repositories | Repository-level statistics |
| ⚡ Recent Activity | Recent public GitHub activity |
